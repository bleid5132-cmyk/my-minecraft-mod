# Priest Vestments — облачение священника (Fabric, Minecraft 1.20.1)

Золотое облачение с 3D-моделью:
- **Воротник** (голова) — невысокий воротник вокруг шеи, сзади выше
- **Фелонь** (грудь) — короткая спереди, длинная сзади, с наперсным крестом и поручами
- **Подризник с епитрахилью** (ноги) — белый подризник, епитрахиль с пуговицами, пояс и палица

## Скачать
https://github.com/bleid5132-cmyk/my-minecraft-mod/releases/latest — файл `vestments-1.0.0.jar`.

## Установка (папка `.minecraft/mods`)
1. Fabric Loader для 1.20.1
2. Fabric API для 1.20.1
3. Armor Model API для 1.20.1 (Fabric) — https://modrinth.com/mod/armor-model-api
4. `vestments-1.0.0.jar`

## Крафт
- Воротник: жёлтая шерсть + золотой слиток + жёлтая шерсть (в ряд)
- Фелонь: 7 жёлтой шерсти + золотой слиток в центре (как нагрудник)
- Подризник: 6 белой шерсти + золотой слиток вверху по центру (как поножи)

Модель и текстура генерируются скриптом `tools/gen_vestments.py`.
