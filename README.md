# My Mod (Fabric, Minecraft 1.20.1)

Пробный мод: добавляет **Рубин** (вкладка «Ингредиенты» в креативе, крафт: алмаз + редстоун).

## Скачать готовый мод

Последняя сборка: **https://github.com/bleid5132-cmyk/my-minecraft-mod/releases/latest** — скачай `mymod-1.0.0.jar`.

## Установка

1. Установи Fabric Loader для Minecraft 1.20.1 (fabricmc.net/use).
2. Положи в папку `.minecraft/mods`:
   - `mymod-1.0.0.jar`
   - Fabric API для 1.20.1 (Modrinth или CurseForge)
3. Запусти игру с профилем Fabric.

Сборка запускается автоматически на GitHub (вкладка Actions) при каждом изменении.
